# agentgo

> **Английский README является канонической документацией.**
> Эта страница — локализованный обзор, а не полный перевод.

`agentgo` превращает артефакт `AgentDeployment` в сервис агентов, который можно самостоятельно развернуть и который работает по стандартным протоколам. Артефакт описывает мультиагентные графы с корневым агентом, делегированными подагентами, параметрами модели и разрешенными инструментами MCP; runtime оркестрирует их выполнение и предоставляет результат через AG-UI, A2A и Agent Card.

Делегирование от корневого агента к подагентам выполняется как локальный граф ADK, а не через A2A. A2A предназначен для внешних машинных клиентов и удаленных агентов.

## Основное

- **Deployment-first**: вызывающая сторона сохраняет пользователей, бизнес-данные, диалоги и UX.
- **Protocol-native**: AG-UI для браузеров; A2A и Agent Card для внешних машинных клиентов и удаленных агентов; MCP для инструментов.
- **Operations-ready**: идентификация Bearer / OIDC / mTLS, аудиторские доказательства, Prometheus / OpenTelemetry и проверки работоспособности.
- **Self-contained examples**: минимальный браузерный чат и ассистент для пояснений по клику.
