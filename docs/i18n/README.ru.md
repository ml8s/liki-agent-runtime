# agentgo

> **Английский README является канонической документацией.**
> Эта страница — локализованный обзор, а не полный перевод.

`agentgo` превращает артефакт `AgentDeployment` в self-hosted сервис агентов, работающий по стандартным протоколам. Он выполняет графы агентов, оркестрирует вызовы LLM и инструменты MCP, а также предоставляет результат через AG-UI, A2A и Agent Card.

## Основное

- **Deployment-first**: вызывающая сторона сохраняет пользователей, бизнес-данные, диалоги и UX.
- **Protocol-native**: AG-UI для браузеров, A2A и Agent Card для машинных клиентов, MCP для инструментов.
- **Operations-ready**: идентификация Bearer / OIDC / mTLS, аудиторские доказательства, Prometheus / OpenTelemetry и проверки работоспособности.
- **Self-contained examples**: минимальный браузерный чат и ассистент для пояснений по клику.

## Примеры

- [simple-chat](../../examples/simple-chat): минимальный браузерный чат AG-UI.
- [agentgo-assistant](../../examples/agentgo-assistant): ассистент для пояснений по клику.
