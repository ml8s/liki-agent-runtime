# Logo assets

The brand-family source assets are managed in the shared brand workspace.
These runtime assets are copies of that canonical mark.

`logo.svg` is a 15-fish circular school. It contains five colors and three
sizes; every color/size pair appears exactly once. Fish point outward around
the ring.
