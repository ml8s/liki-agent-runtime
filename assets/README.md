# Logo assets

The brand-family source assets are managed in the shared brand workspace.
These runtime assets are copies of that canonical mark.

`logo.svg` is a compact 15-fish circular school centered at radius `270` in
the `1024` viewBox. It contains five colors and three sizes; every
color/size pair appears exactly once. Fish point inward around the ring, and
overlaps use clockwise right-over-left layering.
