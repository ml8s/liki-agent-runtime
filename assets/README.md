# Logo assets

`logo.svg` is the canonical mark: 21 yin-yang fish arranged as one dense circular school, with each color represented once at small, medium, and large sizes.

## Sizes

| File | Use |
|---|---|
| `logo-16.png` | tiny UI badges |
| `logo-24.png` | compact toolbar icons |
| `logo-32.png` | small icons |
| `logo-48.png` | list and avatar icons |
| `logo-64.png` | medium icons |
| `logo-128.png` | cards and dialogs |
| `logo-256.png` | social previews |
| `logo-512.png` | store / marketing assets |
| `logo-1024.png` | large export |

## Palette

The seven hues are Material Design 600-series shades, chosen for balanced saturation and accessibility across a circular sequence.

| Hue | Hex |
|---|---|
| Red | `#E53935` |
| Orange | `#FB8C00` |
| Amber | `#FFB300` |
| Green | `#43A047` |
| Cyan | `#00ACC1` |
| Blue | `#1E88E5` |
| Purple | `#8E24AA` |
