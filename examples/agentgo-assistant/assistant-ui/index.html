agentgo

Turn an AgentDeployment artifact into a production-ready agent service.

What agentgo does

agentgo is a standalone runtime for agent graphs. You declare an AgentDeployment artifact; agentgo runs the agent tree, orchestrates model calls and MCP tools, and serves them through standard protocols.

Your product does not import agent infrastructure. It consumes a deployed service.

How it works

  1. Write a deployment artifact with agents, prompts, and tool allowlists.
  2. Point agentgo at your model provider and MCP servers.
  3. Call AG-UI or A2A from your product.

Quick start

cd examples/chat
make setup
# Edit .env and set AGENTGO_LLM_API_KEY
make run

Open http://localhost:8080/ after the stack is healthy.

Served interfaces

  • AG-UI over SSE for streaming browser sessions.
  • A2A JSON-RPC for machine clients.
  • Agent Card discovery for capability lookup.
